# Installation

Follow these three steps in order to get SparkVerse running on your Mac:

| Step | What | Time |
|---|---|---|
| **1** | [Unity Setup](unity-setup.md) — Clone the repo, open the project in Unity Hub | ~15 min |
| **2** | [MQTT Broker](mqtt-broker.md) — Install and configure Mosquitto via Homebrew | ~5 min |
| **3** | [Python Dependencies](python-dependencies.md) — Install packages for the camera detection script | ~5 min |

!!! info "Platform"
    This guide is written for **macOS on Apple Silicon** (M1 / M2 / M3 / M4).
    The project has been tested on Unity 6.3 LTS and Mosquitto 2.1.2.
