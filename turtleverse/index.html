    TurtleVerse¶

    TurtleVerse is the TurtleBot3 variant of the SparkVerse hybrid HIL platform. Instead of SparkNodes tracked by an overhead camera (as in the Monash campus setup), TurtleVerse uses TurtleBot3 Burger differential-drive robots localised by a Qualisys motion capture system.

    The core architecture remains the same — MQTT as the communication backbone, Unity as the visualisation and digital-twin engine — but the perception and actuation layers are swapped:

    SparkVerse (Monash) TurtleVerse (IIT Bombay)
    Robots SparkNodes (custom 2WD) TurtleBot3 Burger (ROS2)
    Localisation Overhead camera + OpenCV Qualisys motion capture (6-DOF)
    Robot control Direct MQTT → SparkNode firmware MQTT → ROS2 bridge → TurtleBot3
    Location Monash University, Australia IIT Bombay, India

    Architecture¶

    The system forms a closed Hardware-in-the-Loop control cycle running at 20 Hz. All subsystems communicate through a central MQTT broker on the Mac.

    MQTT Topic Tree¶

    All TurtleVerse topics live under the turtle_verse/ namespace:

    turtle_verse/
├── robot1/
│   ├── pose              # Published by run_qtm.py (from Qualisys)
│   └── cmd_vel           # Published by SwarmCommander.py
├── robot2/
│   ├── pose
│   └── cmd_vel
├── robot3/
│   ├── pose
│   └── cmd_vel
├── simulated1/
│   ├── pose              # Published by SimulatedBurger.cs (from Unity)
│   └── cmd_vel           # Consumed by SimulatedBurger.cs
├── simulated2/
│   ├── pose
│   └── cmd_vel
└── fleet/
    └── system            # E-STOP / PAUSE (global)

    Payload Formats¶

    Pose (turtle_verse/{name}/pose):

    {"x": 1.2345, "y": 0.6789, "theta": 1.5708}

    All values are in metres and radians (right-handed Cartesian).

    Command Velocity (turtle_verse/{name}/cmd_vel):

    {"linear": 0.12, "angular": 0.3}

    Linear velocity in m/s, angular velocity in rad/s. Clamped to TurtleBot3 Burger hardware limits: ±0.22 m/s linear, ±2.84 rad/s angular.

    Components at a Glance¶

    Component Language Role
    run_qtm.py Python Streams Qualisys MoCap poses to MQTT
    mac_fleet_bridge.py Python (ROS2) Bridges MQTT velocity commands to ROS2 /cmd_vel topics
    SwarmCommander.py Python Central swarm controller (cyclic pursuit / leader-follower)
    commander_square.py Python Same controller with leader-follower square defaults
    RealRobotTracker.cs C# (Unity) Mirrors physical robot poses inside Unity
    SimulatedBurger.cs C# (Unity) Fully simulated digital-twin robot in Unity
    MqttPayloads.cs C# (Unity) Shared serialisable data classes for MQTT JSON
